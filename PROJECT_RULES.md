# PROJECT_RULES

## Proposito del proyecto

- Esta app sera una interfaz visual moderna para ActivityWatch.
- ActivityWatch seguira recogiendo los datos en local.
- Esta app no sustituye ActivityWatch.

## Privacidad y alcance

- Esta app no debe enviar datos a servidores externos.
- No se anadira backend propio en el MVP.
- No se conectara ni modificara la configuracion de ActivityWatch sin indicacion explicita.

## Stack fijo

- React
- JavaScript
- Vite
- Tailwind CSS

## Reglas de implementacion

- No anadir librerias nuevas sin justificarlo antes.
- Mantener componentes pequenos, reutilizables y faciles de entender.
- Priorizar una estructura clara y escalable antes que soluciones rapidas o acopladas.
- Evitar complejidad innecesaria en la primera version.

## Flujo de trabajo

- Despues de cada tarea, actualizar la documentacion correspondiente.
- Despues de cada tarea, explicar con claridad los cambios realizados.
- Antes de implementar integraciones reales, validar primero la estructura, la UI y el modelo de datos con mocks.
